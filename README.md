# Beecrowd 1036 - Fórmula de Bhaskara



## Descrição



Este programa resolve o problema 1036 do Beecrowd.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém três valores de ponto flutuante A, B e C.



## Saída



O programa apresenta as duas raízes da equação no formato:



**R1 = resultado**

**R2 = resultado**



Caso não seja possível calcular as raízes, apresenta:



**Impossivel calcular**
